A tiny Node program (stdlib only, deterministic) that writes one funny loading-screen tip (166 characters) to `entry.txt`. The tip jokes that the loading bar is mostly theatre — a small, human moment for anyone stuck waiting on a build, a game, or another loading bar.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
